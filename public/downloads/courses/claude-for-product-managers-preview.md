# Free Preview: Claude for Product Managers

This is Day 1 of the 7-day course.

## Day 1 Outcome

Turn a messy feature idea into a clear one-page product brief.

## Use This Prompt

```text
You are a senior product manager helping me turn a rough idea into a clear
product brief.

Ask clarifying questions only if the missing information would materially
change the scope. Otherwise, make reasonable assumptions and label them.

Create:
1. Target user
2. Pain/problem
3. Desired outcome
4. Proposed feature
5. Non-goals
6. Success metric
7. Key risks
8. Open questions
9. One-paragraph executive summary

Here is the rough idea:
[paste idea here]
```

## Example Input

```text
Users keep asking for a way to save useful Claude prompts and find them later.
Right now they paste prompts into docs or Slack. We want a simple feature that
lets them save, tag and reuse prompts inside our app.
```

## Expected Output Shape

```markdown
# Product Brief: Saved Prompt Library

## Target User
Power users who repeatedly use Claude for recurring workflows.

## Problem
Useful prompts are scattered across docs, chats and browser bookmarks, so users
lose the exact instructions that previously worked.

## Desired Outcome
Users can save, tag, search and reuse proven prompts without leaving the app.

## Proposed Feature
A lightweight prompt library with save, tag, search and copy actions.

## Non-Goals
- Public prompt marketplace
- Team permissions
- AI-generated prompt scoring

## Success Metric
25% of weekly active users save at least one prompt within 30 days.
```

## Assignment

Run the prompt on one real product idea you are considering. Save the output as
`product-brief.md`. In the full course, Day 2 turns this into user stories and
acceptance criteria.
